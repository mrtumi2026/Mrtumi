## Finalized Architecture & Approved Business Decisions

| ID | Topic | Decision | Status |
|---|---|---|---|
| **ADR-001** | **Application Architecture & Hosting Target (`BestWebHostBD`)** | Retain and harden the existing **Node.js + Express + EJS Modular Monolith** across all 4 portals (`Storefront`, `Admin`, `Vendor`, `Reseller`), deploying via BestWebHostBD's owner-confirmed **Node.js + SSH + MySQL** hosting environment (`docs/ARCHITECTURE.md`, `docs/CPANEL_COMPATIBILITY.md`). Do not introduce SPA frontend frameworks or microservices. | `IMPLEMENTED` |
| **ADR-002** | **Branding & Default Language** | Default language is **Bangla (`bn`)** with **English (`en`)** toggle (`src/config/env.js`). Preserve and use owner's existing **Mr. Tumi Grocery & Gift** branding assets where available; create clean original Mr. Tumi vector assets in Phase 04 for any missing pieces. | `IMPLEMENTED` |
| **ADR-003** | **GitHub Version Control & Push Policy** | Commit and push verified, secret-scanned project changes to `origin/arena/8689c974-mrtumi` (`https://github.com/mrtumi2026/Mrtumi.git`), preserving Phase 01 history (`3611777`) and never force-pushing, committing secrets/dumps, or deploying to production without explicit owner approval. | `IMPLEMENTED` |
| **ADR-004** | **Money Representation (`BDT` Minor Units)** | Store all monetary values as `BIGINT` integer minor units (`paisa`, `৳1.00 = 100 paisa`) in MySQL from Phase 03 onward (`docs/MYSQL_MIGRATION_PLAN.md` §3); perform 100% of pricing, discount, shipping, advance-payment, commission, and COD-balance math server-side inside transactions. | `IMPLEMENTED` |
| **ADR-005** | **Order OTP & Advance Payment Rules** | Both **Order OTP** and **Advance Payment** are configurable in Admin Settings with explicit `OFF` modes (`OFF`, `ALL_COD`, `OUTSIDE_DHAKA_OR_HIGH_VALUE` for OTP; `OFF`, `SHIPPING_FEE_ONLY`, `FIXED_AMOUNT`, `PERCENTAGE` for Advance Payment). | `IMPLEMENTED` |
| **ADR-006** | **Inventory Ownership (Warehouse vs Vendor Stock)** | **In-house and Reseller orders** draw from Mr. Tumi warehouse stock (`stock_ledger`), crediting reseller margin on `Completed` and reversing on return/cancel. **Vendor products** maintain separately tracked vendor stock, subject to Admin product approval and commission rules. | `IMPLEMENTED` |
| **ADR-007** | **CGNAT-Safe Fraud & IP Restriction Policy** | Combine phone/account velocity, TTL cooldowns, OTP step-up, and manual review queue so shared Bangladesh mobile carrier CGNAT IPs are never blindly auto-rejected; require Admin audit reason for permanent blocks. | `IMPLEMENTED` |
| **ADR-008** | **HRM SME Salary Formula** | Monthly salary calculation follows `Basic + Bonus/Allowance − Leave/Advance Deduction = Net Payable`, requiring explicit Admin approval before recording payout. | `IMPLEMENTED` |
| **ADR-009** | **Production Database (`MySQL` Only) & Dialect Portability** | Use **MySQL (`InnoDB`, `utf8mb4_unicode_ci`)** exclusively as the production database (`src/config/env.js` blocks `DB_CLIENT=sqlite` when `NODE_ENV=production`). Keep DDL portable across **MySQL 5.7+, MySQL 8.0+, and MariaDB 10.3+** (`docs/MYSQL_MIGRATION_PLAN.md`) until exact server version (`SELECT VERSION();`) is confirmed on BestWebHostBD. | `IMPLEMENTED` |
| **ADR-010** | **Phase 03 Staged SQLite-to-MySQL Transition** | Convert Phase 03 core infrastructure callers (`sessionManager.js`, `auth.js`, `adminAuth.js`, `server.js` error logging, `/health`) to async MySQL repositories first, enforce runtime `assertSqliteAllowed()` blocking SQLite in `production`/`DB_CLIENT=mysql`, preserve local `data/pholbazar.db*` untouched, and convert the remaining 8 feature route files (`439` calls) module-by-module in Phases 05–18 (`docs/PHASE_03_DB_TRANSITION.md`). | `IMPLEMENTED` |
| **ADR-011** | **Phase 04 Implementation Gate** | Phase 04 implementation (`Mr. Tumi Grocery & Gift` branding system, Bangla/English UI dictionary toggle, responsive shared components, and `৳`/`Asia/Dhaka` display formatters) requires explicit owner approval at the end of Phase 03. | `OWNER APPROVAL REQUIRED` |
