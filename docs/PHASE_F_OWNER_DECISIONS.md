# Phase F — Owner Decision Register

**Purpose:** capture decisions needed to close Phase F production-readiness gates. This register intentionally contains no guessed thresholds, periods, provider choices, policies, credentials, or named owners. Owners must enter approved values through the organization’s controlled decision process; do not place secrets here.

**Current review context:** as of 2026-11-04, the Arena branch has Phase F documentation and non-production tooling. A duplicate migration version `0028` remains in the active branch; MySQL/MariaDB migration CI and Browser E2E are blocked by it. The backup/restore rehearsal is wired into CI but has not completed on either database engine. No production host, DB, account, or service has been inspected.

For each decision, record the decision ID, chosen value/policy, approver(s), date, scope, evidence location, review date, and any exceptions in the approved decision system. This file is a checklist/register, not authority to execute the decision.
